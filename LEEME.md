# Mi Financiera — APK para Android

Al subir esta carpeta a GitHub, GitHub compila la app automáticamente (5–8 minutos)
y publica el archivo `MiFinanciera.apk` en la sección **Releases** del repositorio.

Para actualizar la app: reemplace `www/index.html` con la nueva versión y súbalo; se genera un APK nuevo.
Instale el nuevo APK encima del anterior: los datos se conservan.
